# Personal Portfolio Website

## Overview

This is my personal portfolio website built using HTML and CSS. It presents my profile, skills, and web development journey through a clean and modern user interface.

## Features

* Responsive design
* Modern dark theme with purple accents
* Navigation bar
* Hero section
* Profile image
* Hover effects
* CSS transitions
* Flexbox layout
* Mobile-friendly design

## Technologies Used

* HTML5
* CSS3
